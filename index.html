1. Get the files

Paste SharePoint links (or document numbers, if a register is loaded). The browser downloads them with your normal SharePoint sign in, then you drop the downloaded files here. You can also drop files straight from your OneDrive synced folder.

    Why no Microsoft sign in on this page?

    Reading SharePoint directly from a web page needs an app registration in your company's Microsoft 365 (Azure), and IT has to approve it. Without that approval, a page like this one is not allowed to fetch files from SharePoint itself. So the page asks your browser to download each link, the same as clicking it, using the sign in you already have. Nothing is sent to anyone else and no password is asked for or stored. If SharePoint shows a sign in page instead of downloading, sign in to SharePoint in this browser, then press the button again.

    Drop PDFs, folders or zip files here Many at once is fine (200 or more, 1 GB or more).

    2. Check the list

    Number and revision come from the register or the file name (NUMBER_REV.pdf). Fix any that are wrong by typing in the box. Untick a row to leave it out.

    3. Make reading copies

    Each page is turned into a picture at the resolution and quality set in Settings, and the words are kept as hidden text so the copy stays searchable. Originals are never changed.

    4. Get the results

    Batches are made first: reading copies combined into batch-1.pdf, batch-2.pdf and so on, each under the size limit, each starting with a contents page.
